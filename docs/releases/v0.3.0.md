# HDHomeRun 0.3.0

- Add optional shared capacity groups for several HDHomeRun profiles backed by the same server.
- Filter large XMLTV guides to lineup and explicitly mapped channels; handle interleaved channel/programme documents.
- Add GPU compatible playback, bounded Live Rewind, four-tile multiview, recent channels, audio and seek controls, Picture in Picture, and fullscreen.
- Use the shared authenticated playback and cleanup library, with two GPU slots across Live TV plugins.

Validation: repository release checks, shared race and browser lifecycle tests, local emulator playback checks, and MPEG-2/AC-3 to H.264/AAC conversion on the Silo server GPU. Physical HDHomeRun hardware was not available; device tests use local emulators and Dispatcharr.
