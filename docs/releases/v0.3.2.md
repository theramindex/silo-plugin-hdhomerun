# HDHomeRun 0.3.2

- Store EPG schedules in private local SQLite databases and query only the requested channel/time window.
- Load catalog metadata at startup without decoding the entire schedule. Import existing JSON caches in the background; keep the original files for rollback.
- Commit guide rows and metadata together, preserve the last good guide on refresh failure, and keep reads available during imports.
- Raw listings are scoped by endpoint. Explicit station mappings retain source priority, and an empty endpoint response keeps that endpoint's last good guide.

The database uses WAL mode and requires local storage. Legacy JSON files are no longer updated after migration. Existing guide query limits are preserved; SQLite read failures return a temporary error instead of an empty successful guide. No change to Silo's server database is required.
