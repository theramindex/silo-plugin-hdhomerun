# v0.1.0

Initial release of HDHomeRun for the Ramindex Silo fork.

- Connect multiple physical or emulated HDHomeRun HTTP endpoints, with independent tuner limits and health status.
- Browse channels and XMLTV or SiliconDust programme guides, and save profile favorites.
- Combine equivalent stations explicitly for priority-based, busy-tuner failover before playback starts.
- Play MPEG-TS or HLS through authenticated media routes with viewer-owned reservations and disconnect/stop cleanup.
- Retain private channel and guide snapshots through source outages.

Browser playback requires the companion Ramindex Silo loopback streaming relay. Older hosts show an upgrade message. The plugin relays source codecs; browser-incompatible OTA codecs need conversion at the source or a compatible TV client. DRM-protected channels, DVR, and automatic subnet discovery are outside this release.

Verified with HTTP emulators, H.264/AAC browser playback, race tests, and builds for Linux amd64, Linux arm64, and macOS arm64. Physical hardware and SiliconDust authorization remain unverified.
