# HDHomeRun 0.3.1

- Persist large filtered guides in a private compressed cache, retaining the previous JSON format for compatibility. This fixes guide loss after a restart when the upstream is unavailable.
- Bound decoded cache size and retain atomic cache replacement.

Validation: a guide exceeding the previous 64 MiB cache limit now survives restart during an upstream outage. The regression fails before the fix; release checks pass after it.
