# v0.2.0

HDHomeRun now follows Silo's Live TV layout and theme.

- Uses Silo's Midnight Cinema colors, Plus Jakarta Sans, light theme, and readability preferences.
- Adds the familiar Channels, Guide, and My TV navigation, source sidebar, compact channel rows, and player/details panel.
- Displays programme times in a scrollable three-hour guide with half-hour markers.
- Pages large lineups in groups of 60 and requests guide information only for the current page.
- Keeps device setup, multiple endpoints, favorites, and playback in a responsive layout with accessible player controls on smaller screens.

Browser playback continues to require the stream relay support in the Ramindex Silo server. This release changes the plugin UI and does not install that server update.

Verified with the Go race suite, SDK manifest validation, authenticated asset-route tests, desktop/mobile browser checks, and local HLS/MPEG-TS tuner emulators.
